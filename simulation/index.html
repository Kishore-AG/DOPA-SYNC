MODEL NOTES

Simulation contract

Discrete one-second steps; synthetic Poisson arrivals; one vehicle discharged per green step. Opposing approaches share two aggregate queues. A phase switch is available only after minimum green; switching is atomic, so conflicting greens cannot occur.

Metrics reflect the current browser run. Demand scales both configured rates and is recorded in the CSV. Use the same setting and seed for a controlled comparison.
